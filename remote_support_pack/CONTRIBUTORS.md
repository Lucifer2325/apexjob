# Contributors

Thank you to everyone who has contributed to Remote Support Pack! 🎉

## How to Add Yourself

Made a contribution? Please submit a PR adding your name to the list below:

```markdown
- Your Name ([GitHub](https://github.com/username)) - [Contribution Type]
```

**Contribution Types**:
- Feature: New functionality
- Bug Fix: Bug resolution
- Docs: Documentation improvements
- Testing: Test coverage
- Design: UI/UX improvements
- Suggestion: Feature idea

## Recognition Tiers

### 🌟 Core Contributors (5+ PRs)
- Early access to new features
- Direct communication channel
- Mention in release notes

### 👨‍💻 Active Contributors (2–4 PRs)
- Listed in README
- Tagged in issues
- Thank you message in releases

### 🙏 All Contributors (1+ PR)
- Listed here
- Public recognition
- Free access to premium features (when available)
